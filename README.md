# Wayloom Shell MVP

Phone-friendly static demo of the dual-route shell:

- Codex / Wayloom chat routes
- Thin HUD
- On-demand drawers (board / capabilities / nodes)
- Profile-specific artifact reader (iCAP / Knowledge)

Demo only. Does not connect to a real Wayloom Host.

## Open on phone

Prefer the raw.githack / htmlpreview link after `index.html` is pushed.
